# 取石子游戏

## 题目描述

Alice 和 Bob 在玩取石子游戏，有 $n$ 堆石子从左到右排成一排，初始时从左到右第 $i$ 堆有 $x_i$ 颗石子。

Alice 和 Bob 轮流操作：

- 轮到 Alice 操作时，Alice 从最左边的堆选至少一个石子，把选中的石子移到第二左的堆。
- 轮到 Bob 操作时，Bob 从最右边的堆选至少一个石子，把选中的石子移到第二右的堆。

若轮到某人无法操作时，当前操作的人输掉游戏。

若 Alice 和 Bob 都使用最优策略，你需要判断 Alice 是否有先手必胜策略。

### 输入格式

第一行输入一个正整数 $T$ ($1 \le T \le 10^5$)，表示数据组数。接下来按如下格式输入 $T$ 组数据：

每组第一行输入一个整数 $n$ ($1 \le n \le 10^6$)。

第二行输入 $n$ 个正整数表示每堆石子数 $x_1, x_2, \dots, x_n$ ($1 \le x_i \le 10^9$)。

保证输入数据中 $\sum n \le 3 \times 10^6$。

### 输出格式

共输出 $T$ 行。

如果 Alice 有先手必胜策略，输出 `YES`，否则输出 `NO`。

#### 样例输入

```
5
5
4 5 4 5 9
3
4 4 1
2
10 9
5
1 2 1 1 2
5
2 1 1 2 1
```

#### 样例输出

```
NO
YES
YES
NO
YES
```

## 题解

**符号定义**

- $P_i = \sum_{j=1}^i x_j$ （前 $i$ 项和）
- $S_i = \sum_{j=n-i+1}^n x_j$ （后 $i$ 项和）
- $k = \lfloor n/2 \rfloor$

**结论（先手 Alice 必胜条件）**
1. $n=1$：必败（NO）
2. $n=2$：必胜（YES）
3. **奇数** $n=2k+1$：  
   $(P_k, P_{k-1}, \ldots, P_1) > (S_k, S_{k-1}, \ldots, S_1)$ 字典序严格大于则 YES，否则 NO。
4. **偶数** $n=2k$：  
   $(P_k, P_{k-1}, \ldots, P_2) \ge (S_{k-1}, S_{k-2}, \ldots, S_1)$ 字典序大于等于则 YES，否则 NO。

**归纳证明思路**
- 按局面参数 $(n, x_1+x_n)$ 字典序强归纳（先比堆数，再比两端和）。任何操作后，要么 $n$ 减 1，要么 $n$ 不变但 $x_1+x_n$ 严格减小，故可归纳。
- **偶数 $n=2k$（A 局面）**：  
  令 $L=(P_k,\ldots,P_2)$，$R=(S_{k-1},\ldots,S_1)$。  
  若 $L \ge R$，Alice **清空最左堆**（将 $x_1$ 全移入第二堆）。堆数变为 $2k-1$（奇数），轮到 Bob。  
  新前缀和 $P'_i = P_{i+1}$，故新左序列恰为 $L$；后缀和不变，新右序列为 $R$。  
  由归纳，奇数 B 局面 Alice 必胜条件为 $\ge$，满足，故 Alice 胜。  
  若 $L < R$，任何操作后均进入必败局面（略）。
- **奇数 $n=2k+1$（A 局面）**：  
  令 $L=(P_k,\ldots,P_2)$，$R=(S_k,\ldots,S_2)$。  
  若 $L > R$，Alice **清空最左堆**，堆数变为 $2k$（偶数），轮到 Bob。新左序列为 $L$，右序列为 $R$。  
  偶数 B 局面要求 $>$，满足，故 Alice 胜。  
  若 $L < R$，必败。  
  若 $L = R$，则比较 $x_1=P_1$ 与 $x_n=S_1$：  
  - $x_1 > x_n$：Alice 从最左移 $x_1-x_n$ 颗到第二堆，使两端相等，进入后手占优局面，必胜。  
  - $x_1 \le x_n$：必败。  
  综上，奇数先手必胜条件等价于 $(P_k,\ldots,P_1) > (S_k,\ldots,S_1)$。

#include<bits/stdc++.h>
#define int long long
#define endl '\n'
using namespace std;
const int N = 1e6 + 10;
const int MOD = 1;
#define MOD debug;
int sz[N];
int pre[N];

void solve() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> sz[i];
        pre[i] = pre[i - 1] + sz[i];
    }
    if (n == 1) {
        cout << "NO" << endl;
        return;
    } else if (n == 2) {
        cout << "YES" << endl;
        return;
    }
    if (n & 1) {
        int dq = 0; //先手必输
        int mid = n / 2;
        for (int k = 1; k <= mid; ++k) {
            int lsum = pre[k];
            int rsum = pre[n] - pre[n - k];
            if (!dq && lsum > rsum) {
                dq ^= 1;
            } else if (dq && lsum < rsum) {
                dq ^= 1;
            }
        }
        if (dq) {
            cout << "YES" << endl;
        } else {
            cout << "NO" << endl;
        }
    } else {
        int dq = 1;
        int mid = n / 2;
        for (int k = 2; k <= mid; ++k) {
            int lsum = pre[k];
            int rsum = pre[n] - pre[n - k + 1]; 
            if (!dq && lsum > rsum) {
                dq ^= 1;
            } else if (dq && lsum < rsum) {
                dq ^= 1;
            }
        }
        if (dq) {
            cout << "YES" << endl;
        } else {
            cout << "NO" << endl;
        }
    }
}

signed main() {

# 搭积木

## **题目描述**

小 W 正在用积木搭建一个巨大的结构。

有 $n$ 块积木，编号为 $1$ 到 $n$。第 $i$ 块积木有两个整数属性 $a_i$ 和 $b_i$。

一开始，小 W 打算一块一块地搭建。对每块积木 $i$，给定一个积木 $f_i$，表示积木 $i$ 必须直接放在积木 $f_i$ 的上方。如果 $f_i = 0$，则积木 $i$ 位于整个结构的最底部。题目保证这些要求是自洽的，并且最终会形成一个包含所有积木的完整结构。

后来，小 W 觉得逐块搭建太无聊了。他想到一种新方法：可以先把若干块积木组装成一个结构，再一次性把整个已组装结构放到另一个结构上。具体地，对于两个不交的连通集合 $A$ 和 $B$，若 $A$ 中存在唯一的点 $x$ 使得 $f_x \in B$，那么 $A$ 就可以被放在 $B$ 的上面。

也就是说，在满足所有原始直接上下关系的前提下，小 W 可以自由选择执行放置操作的顺序，也可以提前组装某些局部结构。

一次放置操作中，假设一个已经组装好的结构被放到另一个结构的上方。令：

$A$ 为上方结构内所有积木的 $a_i$ 之和；
$B$ 为下方承托结构内所有积木的 $b_i$ 之和。

这次放置操作的代价定义为 $A \times B$。

操作完成后，两个结构会合并为一个更大的结构。

注意，下方承托结构指的是当前已经组装在一起的整个结构，而不只是单块积木或它的祖先。

小 W 想知道，在所有合法的搭建顺序中，最小总代价是多少。

### **输入格式**

本题单个测试点内有多组测试数据。

第一行输入一个正整数 $T$ ($1 \le T \le 20$)，表示测试数据组数。

接下来按如下格式输入 $T$ 组数据：

第一行输入一个整数 $n$ ($1 \le n \le 2 \times 10^5$)，表示积木数量。保证单个测试点内所有测试数据的 $n$ 之和不超过 $10^6$。

第二行输入 $n$ 个整数 $a_1, a_2, \dots, a_n$ ($1 \le a_i \le 10^3$)。

第三行输入 $n$ 个整数 $b_1, b_2, \dots, b_n$ ($1 \le b_i \le 10^3$)。

第四行输入 $n$ 个整数 $f_1, f_2, \dots, f_n$。其中 $f_1 = 0$，对于所有 $i > 1$，保证 $1 \le f_i < i$。

### **输出格式**

对于每组数据，输出一行一个整数，表示搭建完整结构所需的最小总代价。

#### **样例输入**

```
1
3
3 10 1
5 1 10
0 1 1
```

#### **样例输出**

```
56
```

#### **注意**

样例中，积木 $2$ 和 $3$ 都必须直接放在积木 $1$ 上方。

如果先把积木 $2$ 放到积木 $1$ 上，代价为 $10 \times 5 = 50$。

此时下方结构包含积木 $\{1,2\}$，其 $b$ 之和为 $5 + 1 = 6$。再放置积木 $3$，代价为 $1 \times 6 = 6$。

总代价为 $50 + 6 = 56$，可以证明这是最优的。

本题输入量较大，建议使用较快速的输入方式（如关闭流同步的 `cin`）。

## 题解

题意可以看成一棵以1为根的树，其中fi是积木i的父亲。每次激活一条树上的边，产 生的贡献为两个连通块权值和的乘积。 设当前连通块的两个权值的和为(A,B)。考虑节点i的任意两个儿子x,y，先放x再放 y 与先放y再放x的收益差，只与$\frac{A_x}{B_x}$和$\frac{A_y}{B_y}$的大小关系有关。先放x更优，当且仅当$\frac{A_x}{B_x}$≥$\frac{A_y}{B_y}$. 因此，应优先处理比值A/B最大的当前结构。每次取出当前比值最大的连通块，将其合 并到父亲所在的当前连通块中。 合并后，父亲所在连通块的(A,B)会发生改变，需要将新的状态重新放入优先队列。使 用并查集维护每个点当前所属连通块的代表元。堆中可能存在已经失效的旧状态，弹出 时跳过已经处理过的代表元即可。 时间复杂度为O(nlogn).

```c++
#include<bits/stdc++.h>
#define double long double
#define int long long
#define endl '\n'
using namespace std;
const int N = 1e6+100;
const double eps = 1e-9;

int n;
int f[N];
int vis[N];

struct type {
    int a;
    int b;
    friend bool operator<(type x, type y) {
        return y.b*x.a<x.b*y.a;
    }
}t[N];

int fa[N];
int ans;

int find(int x) {
    if (fa[x] != x) {
        fa[x] = find(fa[x]);
    }
    return fa[x];
}

void merge(int x,int y) {
    fa[find(x)] = find(y);
}

void solve() {
    ans = 0;
    cin >> n;
    for (int i=1;i<=n;++i) {
        vis[i] = 0;
        fa[i] = i;
    }
    for (int i=1;i<=n;++i) {
        cin >> t[i].a;
    }
    for (int i=1;i<=n;++i) {
        cin >> t[i].b;
    }
    for (int i=1;i<=n;++i) {
        cin >> f[i];
        if (f[i]==0) {
            continue;
        }
    }
    priority_queue<pair<type,int>> q ;
    for (int i=2;i<=n;++i) {
        q.push({t[i],i});
    }
    while (!q.empty()) {
        int x = q.top().second;
        type y = q.top().first;
        q.pop();
        if (vis[x]) {
            continue;
        }
        vis[x] = 1;
        merge(x,f[x]);
        fa[x] = find(x);
        ans += t[x].a * t[fa[x]].b;
        t[fa[x]].a += t[x].a;
        t[fa[x]].b += t[x].b;
        if (fa[x]!=1) {
            q.push({t[fa[x]],fa[x]});
        }
    }
    cout << ans << "\n";
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    int _ = 1;
    cin >> _;
    //	cout<<fixed<<setprecision(1);
    while (_--) {
        solve();
    }
    return 0;
}

```
