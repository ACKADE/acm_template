# 数字游戏

## 题目描述

Input file: standard input  
Output file: standard output  
Time limit: 1 seconds  
Memory limit: 256 megabytes  

给定一个正整数进制 $$B$$。  
你需要构造三个长度为 $$B$$ 的排列 $$P, Q, R$$（即每个序列恰好包含 $$0$$ 到 $$B-1$$ 每个数字一次）。

$$P = (p_1, p_2, \dots, p_B), \quad Q = (q_1, q_2, \dots, q_B), \quad R = (r_1, r_2, \dots, r_B),$$

定义一个序列 $$X = (x_1, x_2, \dots, x_B)$$ 在 $$B$$ 进制下表示的整数为  

$$[X]_B = \sum_{i=1}^B x_i \cdot B^{B-i}.$$

注意序列允许以数字 $$0$$ 开头，因此表示的整数可以小于 $$B^{B-1}$$。  

请你构造三个排列 $$P, Q, R$$，使得它们满足等式（注意加法是在 $$B$$ 进制下的加法）  

$$[P]_B + [Q]_B = [R]_B,$$

并且对于每个位置 $$i\ (1 \le i \le B)$$，$$p_i, q_i, r_i$$ **两两不同**。  

如果不存在这样的构造，请输出 $$-1$$。

### 输入格式

输入仅一行，包含一个整数 $$B\ (2 \le B \le 10^6)$$。

### 输出格式

如果存在合法构造，则输出三行，每行 $$B$$ 个整数，分别表示序列 $$P, Q, R$$ 中的数字，数字之间用空格分隔。  
如果不存在合法构造，则输出一行 $$-1$$。  

若存在多种构造，输出任意一种即可。

#### **样例输入**

```c++
5
```

#### **样例输出**

```c++
-1
```

#### **样例输入**

```c++
6
```

#### **样例输出**

```c++
4 2 5 0 3 1
0 4 1 2 5 3
5 1 0 3 2 4
```

**Note**

$$2 \le B \le 10^6$$。

## 题解

**题目大意与必要条件**

我们要构造 $0 \sim B-1$ 的三个排列 $P,Q,R$，满足竖式加法：

$$[P]_B + [Q]_B = [R]_B$$

并且每一列 $p_i, q_i, r_i$ 三个数字互不相同。

设从第 $i$ 位向第 $i+1$ 位的进位为 $c_{i+1}$（$c_0=0$, $c_B=0$），则每一列满足：

$$p_i + q_i + c_i = r_i + B \cdot c_{i+1}.$$

三个排列的所有数字之和均为 $S = \frac{B(B-1)}{2}$。将所有 $B$ 列的等式相加，设所有进位之和为 $C = \sum_{i=1}^B c_i$，可得：

$$2S + C = S + BC \quad \Longrightarrow \quad C = \frac{B}{2}.$$

因此 $B$ 必须是偶数。结合每一列三个数互异的限制，可以证明只有当 $B$ 为偶数且 $B \ge 4$ 时才有解。所以 $B=2$ 和奇数 $B$ 均无解。

**按列构造（$B \ge 6$）**

令 $n = B/2$。我们首先确定每一列的三个数字以及产生的进位，此时不考虑列的顺序，只把每一列当作一个“三元组”$(p, q, r)$ 以及它向高位的进位 $d$。

用下标 $p = 0, 1, \dots, B-1$ 标识不同的列，并定义：

$$q_p = (p - 2) \bmod B,$$

$$a_p = 
\begin{cases}
1, & p < n, \\
0, & p \ge n,
\end{cases}
\quad \text{然后交换 } a_1 \text{ 与 } a_{n+1}.$$

这样做的目的是保证恰好有 $n = B/2$ 个列的入进位为 $1$，其余为 $0$，且 $a_{p+n} = 1 - a_p$。

接着计算：

$$s_p = p + q_p + a_p, \qquad r_p = s_p \bmod B, \qquad d_p = \left\lfloor \frac{s_p}{B} \right\rfloor.$$

这里 $a_p$ 相当于进入这一列的进位 $c_i$，$d_p$ 相当于从这一列出去的进位 $c_{i+1}$。对于每一列，$(p, q_p, r_p)$ 满足加法关系且三个数字两两不同。

**为什么三个序列都是排列**

- $q_p = (p-2)\bmod B$ 显然是 $0\sim B-1$ 的排列。
- 模 $B$ 下 $r_p \equiv 2p - 2 + a_p$。将 $p = x$ 与 $p = x+n$ 配对，利用 $a_{x+n}=1-a_x$，可得  
  $\{r_x, r_{x+n}\} = \{2x-2,\, 2x-1\} \pmod B$。  
  因此 $R$ 恰好遍历所有偶数和所有奇数各一次，也是排列。
- 通过构造中特殊的调整（如交换 $a_1$ 与 $a_{n+1}$）可以保证对任意 $p$ 有 $p \ne q_p$，$p \ne r_p$，$q_p \ne r_p$。

**恢复列的顺序**

上述过程给出了 $B$ 个列的三元组 $(p, q, r)$ 及其出进位 $d_p$。现在需要将它们排列成从低位到高位的顺序，使得进位前后衔接：第 $i$ 列的出进位 $d_{p_i}$ 必须等于第 $i+1$ 列的入进位 $a_{p_{i+1}}$。

将每一列视为一条有向边 $a_p \to d_p$。由于入进位总和等于出进位总和（均为 $B/2$），图中边 $0\to 1$ 与 $1\to 0$ 的数量相等。在这个只有两个点 $\{0,1\}$ 的有向多重图上，从点 $0$ 出发求一条欧拉回路，得到的边序列即对应从低位到高位的列顺序。按照这个顺序输出 $P, Q, R$ 即可。

整个构造与恢复的复杂度均为 $O(B)$。

**特例 $B = 4$**

$B=4$ 时单独给出一组构造，例如：

```
#include<bits/stdc++.h>
#define int long long
#define endl '\n'
using namespace std;

void solve() {
    int B;
    cin >> B;
    // 奇数或 B=2 无解
    if (B % 2 == 1 || B == 2) {
        cout << -1 << endl;
        return;
    }
    // B=4 特解
    if (B == 4) {
        cout << "0 3 2 1" << endl;
        cout << "1 2 0 3" << endl;
        cout << "2 1 3 0" << endl;
        return;
    }

    // 一般构造 B >= 6 的偶数
    int n = B / 2;
    vector<int> a(B, 0);
    for (int i = 0; i < n; ++i) a[i] = 1;
    swap(a[1], a[n + 1]);   // 关键调整，保证每列三个数字两两不同

    struct Col {
        int p, q, r;
    };
    vector<Col> cols(B);
    vector<int> out_carry(B);
    // 图只有 0,1 两个顶点
    vector<pair<int, int>> graph[2]; // (v, col_index)

    for (int p = 0; p < B; ++p) {
        int q = (p - 2 + B) % B;
        int s = p + q + a[p];
        int r = s % B;
        int d = s / B;          // 出进位
        cols[p] = {p, q, r};
        out_carry[p] = d;
        graph[a[p]].emplace_back(d, p);
    }

    // Hierholzer 非递归找欧拉回路（从 0 开始）
    vector<int> euler;
    stack<int> node_st;
    stack<int> edge_st;   // 存列下标
    node_st.push(0);

    while (!node_st.empty()) {
        int u = node_st.top();
        if (!graph[u].empty()) {
            auto [v, idx] = graph[u].back();
            graph[u].pop_back();
            node_st.push(v);
            edge_st.push(idx);
        } else {
            node_st.pop();
            if (!edge_st.empty()) {
                euler.push_back(edge_st.top());
                edge_st.pop();
            }
        }
    }
    reverse(euler.begin(), euler.end()); // 此时 euler 是从低位到高位的列顺序

    // 高位到低位输出
    for (int i = B - 1; i >= 0; --i) {
        int id = euler[i];
        cout << cols[id].p << " \n"[i == 0];
    }
    for (int i = B - 1; i >= 0; --i) {
        int id = euler[i];
        cout << cols[id].q << " \n"[i == 0];
    }
    for (int i = B - 1; i >= 0; --i) {
        int id = euler[i];
        cout << cols[id].r << " \n"[i == 0];
    }
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    int _ = 1;
    // cin >> _;
    while (_--) {
        solve();
    }
    return 0;
}
```

# 放大的徽章

## 题目描述

Input file: standard input  
Output file: standard output  
Time limit: 3 seconds  
Memory limit: 512 megabytes  

平面上给定两个有限格点集合 $A$ 和 $B$。设 $P = \operatorname{conv}(A)$，$Q = \operatorname{conv}(B)$ 分别为它们的凸包。输入中可能包含重复点。

对于一个正整数 $k$，将 $P$ 关于原点放大 $k$ 倍，得到多边形 $kP$。  
如果整数向量 $(u, v)$ 使得平移后的多边形 $kP + (u, v)$ 与 $Q$ 至少有一个公共点，则称 $(u, v)$ 是合法的。边界相交也算相交。

对于每个询问 $k$，求合法整数向量 $(u, v)$ 的数量，并对 $998244353$ 取模。

### 输入格式

第一行包含三个整数 $n, m, q$ ($3 \le n, m \le 2 \times 10^5$，$1 \le q \le 2 \times 10^5$)，分别表示 $A$ 中点的个数、$B$ 中点的个数和询问次数。  
接下来 $n$ 行，每行包含两个整数 $x_i, y_i$ ($-10^9 \le x_i, y_i \le 10^9$)，表示 $A$ 中的一个点。  
接下来 $m$ 行，每行包含两个整数 $x_i, y_i$ ($-10^9 \le x_i, y_i \le 10^9$)，表示 $B$ 中的一个点。  
接下来 $q$ 行，每行包含一个整数 $k$ ($1 \le k \le 10^{18}$)，表示一次询问。

保证 $P$ 和 $Q$ 的面积均为正。

### 输出格式

对于每个询问，输出一行一个整数，表示合法整数向量的数量对 $998244353$ 取模的结果。

#### **样例输**入

```c++
6 5 4
0 0
2 0
2 1
0 1
1 0
1 1
0 0
3 0
1 2
0 1
1 1
1
2
5
10
```

#### **样例输出**

```c++
20
36
108
308
```

**Note**

在样例中，$P$ 是顶点为 $(0,0),(2,0),(2,1),(0,1)$ 的矩形，$Q$ 是顶点为 $(0,0),(3,0),(1,2),(0,1)$ 的四边形。  
可以算出 $2S_P = 4$，$2S_Q = 7$，$B_P = 6$，$B_Q = 7$，且 $2S_{Q+(-P)} = 25$。因此询问 $k$ 的答案为 $2k^2 + 10k + 8$。  
代入 $k=1,2,5,10$，答案分别为 $20,36,108,308$。

## 题解

**Minkowski 和**

存在 $p \in P, q \in Q$ 使 $kp + t = q$，等价于
$$t \in Q + (-kP).$$
因此答案就是整点多边形 $R_k = Q + (-kP)$ 中的格点数。

只需显式计算一次 $R_1 = Q + (-P)$：先求两个凸包，再按极角归并两凸多边形的边向量，可在 $O(n+m)$ 时间内求出 Minkowski 和。之后每个询问代入关于 $k$ 的多项式即可。

**Pick 定理与二次多项式**

记 $S(X)$ 为 $X$ 的**二倍面积**，$B(X)$ 为边界上的整点数。由 Pick 定理，多边形 $X$ 内部的整点数为
$$I(X) = \frac{S(X) - B(X) + 2}{2},$$
总整点数为
$$|X \cap \mathbb{Z}^2| = I(X) + B(X) = \frac{S(X) + B(X)}{2} + 1.$$

利用 Minkowski 混合面积与边界长度的线性性质：
$$S(R_k) = S(Q) + k^2 S(P) + k \cdot C, \quad B(R_k) = B(Q) + k \cdot B(P),$$
其中 $C = S(R_1) - S(Q) - S(P)$。

因此 $|R_k \cap \mathbb{Z}^2|$ 是关于 $k$ 的二次多项式：
$$|R_k \cap \mathbb{Z}^2| = \frac{S(P)}{2} k^2 + \frac{C + B(P)}{2} k + \left( \frac{S(Q) + B(Q)}{2} + 1 \right).$$
所有运算在模 $998244353$ 下进行，直接计算即可。

 **实现细节**

- 对点集去重，并删除凸包边界上的共线中间点，确保凸包顶点为严格凸多边形。
- 面积、叉积使用 `__int128` 避免坐标相乘溢出。
- 边界整点数：对每条边，贡献为 $\gcd(|\Delta x|, |\Delta y|)$。
- 预处理时间复杂度 $O((n+m)\log (n+m))$，每个询问 $O(1)$，空间 $O(n+m)$。
