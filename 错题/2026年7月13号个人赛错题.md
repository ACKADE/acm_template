## 1.路径

### 题目大意

给一张*N* 个点、*M* 条边的无向图无向图，每个点有一种颜色，共 $K$ 种颜色。求有多少条至少包含两个点的简单路径，使得路径中不存在颜色相同的点。路径方向不同算不同路径。

数据范围：$N,M\le 300000$，$K\le 5$；最后一个子任务为 $N,M\le 100000$，$K\le 5$。答案不超过 $10^{18}$。

### 题解

颜色数很小，可以对颜色集合做状压 DP。令：

$$dp[mask][v]$$

表示当前路径颜色集合为 $mask$，且最后一个点为 $v$ 的有向路径数量。初始化每个单点路径：

$$dp[1<<c_v][v]=1.$$

枚举 $mask$ 和结尾点 $v$，沿边扩展到邻点 $u$。若 $u$ 的颜色不在 $mask$ 中，则可以转移。由于每次都加入一种新颜色，路径不可能重复经过点。

最后统计所有包含至少两种颜色的状态。DP 是按方向扩展的，所以会自然区分 $1-2$ 和 $2-1$。

复杂度 $O(2^K(N+M))$，空间 $O(2^K N)$。

### 标称

```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N = 5e5 + 10;
const int MOD = 1;
#define MOD debug;
int dp[(1 << 5) + 10][N];
vector<int> ljb[N];
int c[N];

void solve() {
    int n, m, k;
    cin >> n >> m >> k;
    for (int i = 0; i < n; i++) {
        cin >> c[i];
        c[i]--;
        dp[1 << c[i]][i] = 1;
    }
    int a, b;
    for (int i = 1; i <= m; i++) {
        cin >> a >> b;
        a--;
        b--; //让颜色序号从0开始，方便后面进行移位计算
        ljb[a].push_back(b);
        ljb[b].push_back(a);
    }
    for (int zt = 1; zt < (1ll << k); zt++) {
        //起始状态,目前的状态，我们用目前的状态往后更新
        for (int i = 0; i < n; i++) {
            //起始点，目前路径往哪个方向扩展
            for (auto to: ljb[i]) {
                if (zt & (1 << c[to])) {
                    continue;
                }
                dp[zt | (1ll << c[to])][to] += dp[zt][i];
            }
        }
    }
    int ans = 0;
    for (int zt = 0; zt < (1 << k); zt++) {
        if (__builtin_popcount(zt) >= 2) {
            //筛选长度大于2的状态
            for (int i = 0; i < n; i++) {
                ans += dp[zt][i];
            }
        }
    }
    cout << ans << endl;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int _ = 1;
    //    cin>>_;
    //    cout<<fixed<<setprecision(1);
    while (_--) {
        solve();
    }
    return 0;
}
```

## 2.巧克力节

### 题目大意

有 $n$ 颗互不相同的糖，要放入 $k$ 个相同盒子。每颗糖恰好放一个盒子，每个盒子非空，盒内顺序重要，且每个盒子最大的糖必须放在第一个。求方案数。

数据范围：$1\le k\le n\le 5000$，答案对 $10^9+7$ 取模。

### 题解

按糖的大小从大到小处理。设 $dp[i][j]$ 表示已经处理最大的 $i$ 颗糖，形成 $j$ 个盒子的方案数。

处理第 $i+1$ 颗糖时：

- 新开一个盒子：$dp[i+1][j+1]+=dp[i][j]$；
- 放入已有盒子：当前糖比已处理糖都小，可以插到已有糖之后的任意位置。已处理了 $i$ 颗糖，所以共有 $i$ 个插入位置，$dp[i+1][j]+=dp[i][j]\cdot i$。

滚动数组即可。

复杂度 $O(nk)$，空间 $O(k)$。

### 标称

```cpp
#include <bits/stdc++.h>
using namespace std;

const long long MOD = 1000000007LL;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    cin >> n >> k;

    vector<long long> dp(k + 2, 0), ndp(k + 2, 0);
    dp[0] = 1;

    for (int i = 0; i < n; i++) {
        fill(ndp.begin(), ndp.end(), 0);
        for (int j = 0; j <= k; j++) {
            if (!dp[j]) continue;
            if (j + 1 <= k) {
                ndp[j + 1] = (ndp[j + 1] + dp[j]) % MOD;
            }
            ndp[j] = (ndp[j] + dp[j] * i) % MOD;
        }
        dp.swap(ndp);
    }

    cout << dp[k] << '\n';
    return 0;
}
```
