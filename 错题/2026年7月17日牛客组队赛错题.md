## 题目描述

Given an integer $n$, you need to construct a set $S$ consisting of no more than $(2n+2)$ different points in three-dimensional Euclidean space such that for each point $P \in S$, there are exactly $n$ different points $Q \in S$ that $\text{dis}(P,Q) = 1$, where $\text{dis}(P,Q)$ is the Euclidean distance between $P$ and $Q$.

Regular icosahedron, a feasible solution for $n=5$.

To tolerate the precision error, let $\epsilon = 0.01$, and your answer will be considered correct if and only if:
- For any two different points $P,Q \in S$, $\text{dis}(P,Q) > \epsilon$;
- For each point $P \in S$, there are exactly $n$ different points $Q \in S$ such that $1-\epsilon < \text{dis}(P,Q) < 1+\epsilon$.

### 输入描述

The first line of the input contains an integer $T$ ($1 \le T \le 100$), indicating the number of test cases. For each test case:

The only line contains an integer $n$ ($1 \le n \le 100$).

### 输出描述

For each test case:

Output an integer $m$ ($1 \le m \le 2n+2$) in the first line, indicating the number of points in $S$.

Then output $m$ lines, each of which contains three real numbers $x$, $y$, and $z$ ($-100 \le x,y,z \le 100$), indicating the coordinates of a point in $S$.

It can be shown that a feasible solution always exists under the given constraints, and if there are multiple feasible solutions, you may output any.

## 题解

题目要求构造一个三维点集，使得每个点恰好有 \(n\) 个距离约为 1 的邻居，且所有点两两距离大于容差 $\epsilon=0.01$。题解利用精度容差和几何近似来“骗过”检查器，称为 CheckerHack 题。核心思想是把点放在两个平行平面 $z=0$ 和 $z=1$ 上，每组各放 $n$个点。由近似公式 $\sqrt{1+x^2}\approx 1+x^2/2$可知，当水平投影距离 $d<\sqrt{2\epsilon}$ 时，垂直距离为 1 的两点间欧氏距离落在 $(1, 1+\epsilon)$ 内。为了让跨平面的任意两点都满足该条件，把每组点的水平坐标限制在一个半径约为 $\sqrt{2\epsilon}/2$ 的小圆内，这样任意跨平面点对的水平距离不超过圆的直径（即小于$\sqrt{2\epsilon}$，从而确保距离严格在 $1$ 到$1+\epsilon$ 之间。同平面内的点因为距离在平面内，只要用边长略大于 $\epsilon$ 的正方形网格在圆内密铺放置点，即可保证同组内点距 $>\epsilon$ 且远小于 1，不会意外形成新的近似单位距离邻居。当 $n\le 100$、$\epsilon=0.01$ 时，半径约 0.07 的圆内足以放入 100 个间距大于 0.01 的点。这样构造出的总点数为 $2n\le 2n+2$，每个点恰好与另一平面的 $n$ 个点距离约为 1，满足题目全部容差要求。

```c++
#include<bits/stdc++.h>
#define int long long
#define endl '\n'
using namespace std;
const int N = -1;
const int MOD = 1;

void solve() {
    int n;
    cin >> n;
    
    const double eps = 0.01;
    const double R = sqrt(eps / 2.0);          // 小圆半径 ≈ 0.0707
    const double d = 0.0105;                   // 网格间距，>0.01 即可
    vector<pair<double, double>> pts;          // 存放水平坐标 (x, y)
    
    // 在半径 R 的圆内用正方形网格生成点
    for (double x = -R; x <= R; x += d) {
        for (double y = -R; y <= R; y += d) {
            if (x * x + y * y <= R * R + 1e-12) {
                pts.emplace_back(x, y);
                if ((int)pts.size() == n) break;
            }
        }
        if ((int)pts.size() == n) break;
    }
    
    // 输出总点数 2n
    cout << 2 * n << endl;
    cout << fixed << setprecision(10);
    
    // 平面 z = 0 上的 n 个点
    for (auto [x, y] : pts) {
        cout << x << " " << y << " " << 0.0 << endl;
    }
    // 平面 z = 1 上的 n 个点
    for (auto [x, y] : pts) {
        cout << x << " " << y << " " << 1.0 << endl;
    }
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    int _;
    cin >> _;
    while (_--) {
        solve();
    }
    return 0;
}
```

# 大鱼吃小鱼

**Input file:** standard input  
**Output file:** standard output  
**Time limit:** 4 seconds  
**Memory limit:** 1024 megabytes

## 题目描述
给一个 n×m 的网格，部分格子上有鱼，其余格子是障碍。其中有一条鱼受你控制，可以反复将其移动到上下左右相邻的格子，但不能移出网格：若目标格子有一条大小不超过自身的鱼，则可以吃掉它，自身大小增加 1；若目标格子是障碍或鱼比自身大，则无法移动。
初始时所有格子都是障碍。依次有 q 次操作，操作有两种：
1. 把 (x,y) 处的障碍去除，并放入一条大小为 v 的鱼，要求出这条鱼在你的控制下最多能吃掉多少条鱼。保证 (x,y) 处当前是障碍，且 v 不小于之前放入过的所有鱼的大小。
2. 假设在假想过程开始前，可以将 (x,y) 处鱼的初始大小增加一个非负整数。设在所有可能的增加量中，该鱼理论上最多能吃到 k 条鱼。求为了能吃到 k 条鱼，所需增加的最小大小。保证 (x,y) 处之前放入过鱼。
对于两类操作，吃鱼的过程是假设性的，不会实际改变任何已放入鱼的状态。

### 输入格式
第一行包含三个整数 n, m (1 ≤ n,m, n×m ≤ 2.5×10^5) 和 q (1 ≤ q ≤ 5×10^5)，表示网格的大小和操作数量。
您需要依次处理 q 个操作。对于每个操作，给出加密后的坐标 x′ 和 y′。令 l 为上一个操作的输出结果（对于第一个操作，l=0）。计算解密后的坐标 x = x′ ⊕ l，y = y′ ⊕ l，其中 ⊕ 表示按位异或。保证 1 ≤ x ≤ n，1 ≤ y ≤ m。操作 1 中的 v 未经加密。操作有以下两种：
1. `1 x' y' v`：计算解密后的坐标 x 和 y，把 (x,y) 处的障碍去除，并放入一条大小为 v (1 ≤ v ≤ 10^9) 的鱼，要求出这条鱼在你的控制下最多能吃掉多少条鱼。保证 (x,y) 处当前是障碍，且 v 不小于之前放入过的所有鱼的大小。
2. `2 x' y'`：计算解密后的坐标 x 和 y。假设在假想过程开始前，可以将 (x,y) 处鱼的初始大小增加一个非负整数。设在所有可能的增加量中，该鱼理论上最多能吃到 k 条鱼。求为了能吃到 k 条鱼，所需增加的最小大小。保证 (x,y) 处之前放入过鱼。

### 输出格式
输出 q 行，每行包含一个整数，表示每次操作的答案。

## 题解

按鱼的大小**非降序**加入点，动态维护 **Kruskal 重构树**。

对于每个点 $u$，维护两个值：
- $sz_u$：子树内鱼的数量
- $w_u$：向上走需要的最小大小

对于一条大小为 $v$ 的鱼，假设它走到了点 $x$：
- 此时大小变为 $v + sz_x - 1$
- 若想继续向上走，需要满足 $v + sz_x - 1 \ge w_x$

因此，若一条鱼要走到重构树的根，其初始大小 $v$ 必须满足：
$$v \ge \max_{x \in \text{path}(u \to \text{root})} (w_x - sz_x + 1)$$

为此，除了并查集祖先 $Fa_u$ 外，每个点还需额外维护：
$$Max_u = \max_{x \in \text{path}(u \to Fa_u)} (w_x - sz_x + 1)$$

两类询问的处理

1. **加入一条鱼**（操作 1）  
   将新点按大小插入后，输出所在并查集根节点的 $sz - 1$ 即可。

2. **查询所需最小增加量**（操作 2）  
   对于点 $u$ 上大小为 $v_u$ 的鱼，答案为：
   $$\max(Max_u - v_u, 0)$$

整个过程**不需要显式地建出 Kruskal 重构树**，只需在并查集合并时维护 $Fa$、$sz$、$w$、$Max$ 等信息即可。
