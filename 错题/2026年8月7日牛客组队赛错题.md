# 入侵天使领域行动

## 题目描述

在“入侵天使领域行动”中，仲村由理正尝试破解立华奏电脑的密码。

立华奏的电脑密码可以表示为一个长度为 $n$ 的非负整数数组 $a$。当且仅当最终数组单调不下降时，密码才算被破解。

现在，仲村由理每次可以选择一个非负整数 $k$，并花费 $k$ 的时间。随后，她可以任选数组中的若干个元素，将这些元素同时与 $k$ 进行按位异或操作。

与此同时，另一侧的演唱会作战正遭受教师的压制，因此仲村由理必须尽快完成破解。你，作为这个世界的“神”，想要知道在最优策略下，仲村由理最少需要花费多少时间。

### 输入格式

第一行包含一个整数 $t$（$1 \le t \le 2 \times 10^5$），表示测试组数。

对于每组测试数据：
第一行包含一个整数 $n$（$1 \le n \le 2 \times 10^5$），表示数组长度。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$（$0 \le a_i \le 10^9$），表示初始数组。

保证所有测试数据中 $n$ 的总和不超过 $2 \times 10^5$。

### 输出格式

对于每组数据，输出一行一个整数，表示最少花费的总时间。

#### **样例输入**

```c++
6
2
3 0
2
7 4
2
6 1
3
4 6 3
3
1 2 3
4
1 0 6 5
```

#### **样例输出**

```c++
2
2
4
4
0
2
```

## 题解

核心观察：一次操作 $k$ 可以拆成其所有二进制位上的操作，总代价不变，各位选择的元素集合还能彼此独立。  
同一位没有必要购买多次，因此整个策略可由购买掩码 $M$ 描述，总代价就是 $M$。  
固定 $M$ 后，$a_i$ 中不能修改的部分为  
$r_i = a_i \mathbin{\&} \sim M$，  
可达最大值为 $r_i \mid M$。

*入侵天使领域行动*  
*南京大学命题组*  
*AC.NOWCODER.COM*

从左到右维护前一个值 $pre$。若 $r_i \mid M < pre$，则 $M$ 不可行。  
否则从高到低处理 $M$ 中的位，构造“不小于 $pre$ 的最小可达值”。当前值越小，对后续限制越弱。  
再从高到低决定答案 $M$ 的每一位：尝试令当前位为 $0$，并暂时购买所有尚未决定的低位；若仍不可行，该位才必须取 $1$。  
复杂度 $O(n \log_2 V)$，空间复杂度 $O(n)$。

```c++
#include <bits/stdc++.h>
using namespace std;

int n;
vector<int> a;

// 判断 M 是否可行
bool check(int M) {
    int pre = 0;  // 前一个数最终选的值，初始0因为所有数非负
    for (int x : a) {
        int r = x & ~M;          // 不可更改的部分
        int max_val = r | M;     // 可达最大值
        if (max_val < pre) return false; // 连最大都达不到 pre，失败

        // 构造 >= pre 的最小可达值
        int b = 0;
        for (int bit = 29; bit >= 0; --bit) {
            if ((M >> bit) & 1) {
                // 这一位是自由位
                int low_mask = (1 << bit) - 1;
                int max_low = (r | M) & low_mask; // 假设这一位填0，低位全填最大
                if ((b | max_low) < pre) {
                    b |= (1 << bit); // 必须填1
                }
            } else {
                // 固定位
                b |= (r & (1 << bit));
            }
        }
        pre = b; // 更新 pre
    }
    return true;
}

void solve() {
    cin >> n;
    a.resize(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    int M = 0;
    for (int bit = 29; bit >= 0; --bit) {
        // 尝试让这一位为0，所有更低位置1
        int M_try = M | ((1 << bit) - 1);
        if (!check(M_try)) {
            // 不行，这一位必须买
            M |= (1 << bit);
        }
    }
    cout << M << '\n';  // 总花费就是 M 本身
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int t;
    cin >> t;
    while (t--) solve();
    return 0;
}
```

## 自我分析

这道题在赛场上想到了从高位到低位一层层的遍历，然后想到了把k按位拆开，等价于对所有数按位讨论，贪心的从高位到低位，如果某一位要消除则确定这一位可以随便排，但是就是不清楚怎么写，高位的排列可以影响低位，但是你又必须需要从高位往低位跑，所以就不太清楚这道题怎么写，看了下题解之后，发现这道题类似于二分答案，有点像把问题转化为判定问题，判定某个答案可不可行，这道题想了四个小时没想出来，还是挺妙的，之后可以去补一补，这种从高位枚举到低位，然后把后面全当成0的题目应该也算是一种很好的套路了，这道题蛮好的
