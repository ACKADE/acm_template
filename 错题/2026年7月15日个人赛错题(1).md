# Expressions

## 题目描述

Tomorrow Programming School 的算术课训练中，有一部分内容是只靠心算快速求出给定算术表达式的值。幸运的是，这些表达式只包含正整数，没有括号，并且只包含三种运算：加法、减法和乘法。因此结果一定是整数。并且在入门阶段，学生只需要判断结果的奇偶性，即结果是奇数还是偶数。

不幸的是，在黑板上写表达式的教授非常健忘。他经常在学生已经开始计算时改写表达式中的各种数字，有时甚至多次改写。通常这会改变整个表达式的值，学生不得不从头开始计算。

学生们决定写一个程序来帮助他们。程序的输入是原始表达式，以及之后发生的一系列数值修改。对于每次修改，程序都要计算修改后的表达式值，最好不必每次都从头重新计算整个表达式。

### 输入格式

第一行包含两个整数 `N` 和 `M`，分别表示表达式中的整数个数和之后发生的数值修改次数，满足 `1 <= N,M <= 10^5`。

第二行包含 `N` 个由运算符分隔的整数 `A_1,...,A_N`，满足 `1 <= A_i <= 10^9`。每个运算符是 `+`、`-` 或 `*` 之一。

接下来 `M` 行，每行描述一次数值修改，包含两个整数 `X` 和 `Y`，满足 `1 <= X <= N`，`1 <= Y <= 10^9`，表示表达式中的第 `X` 个数被改成 `Y`。

修改是连续生效的。也就是说，当下一次修改发生在不同位置时，此前对表达式做出的修改仍然保留。

### 输出格式

输出 `M+1` 行。第 `i` 行输出 `even` 或 `odd`，表示应用前 `i-1` 次修改后，表达式的值是偶数还是奇数。

特别地，第一行表示在任何修改发生之前，原始表达式的值是偶数还是奇数。表达式求值遵循标准运算优先级，乘法优先级高于加法和减法。

#### 样例输入 #1

```plain
6 4
11 + 22 * 33 - 44 * 55 * 66
1 2
2 3
4 5
3 5
```

#### 样例输出 #1

```plain
odd
even
odd
odd
odd
```

## 题解

```c++
#include<bits/stdc++.h>
#define int long long
#define endl '\n'
using namespace std;
const int N = 1e6 + 10;
const int MOD = 1;
int sz[N];
int gs[N];
int eve[N];
int siz[N];
int n, m;

void solve() {
    cin >> n >> m;
    string zfc;
    int dq = 1;
    for (int i = 1; i <= n; i++) {
        if (i != 1) {
            cin >> zfc;
            if (zfc == "+") {
                dq++;
            } else if (zfc == "-") {
                dq++;
            }
        }
        cin >> sz[i];
        gs[i] = dq;
    }
    for (int i = 1; i <= n; i++) {
        eve[gs[i]] += 1 - (sz[i] & 1);
    }
    int ans = 0;
    for (int i = 1; i <= dq; i++) {
        if (eve[i] == 0) {
            ans ^= 1;
        }
    }
    if (ans & 1) {
        cout << "odd" << endl;
    } else {
        cout << "even" << endl;
    }
    int x, y;
    while (m--) {
        cin >> x >> y;
        if (eve[gs[x]] == 0) {
            ans ^= 1;
        }
        if ((sz[x] & 1) == 0) {
            eve[gs[x]]--;
        }
        sz[x] = y;
        if ((sz[x] & 1) == 0) {
            eve[gs[x]]++;
        }
        if (eve[gs[x]] == 0) {
            ans ^= 1;
        }
        if (ans & 1) {
            cout << "odd" << endl;
        } else {
            cout << "even" << endl;
        }
    }
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int _ = 1;
    //	cin>>_;
    //	cout<<fixed<<setprecision(0);
    while (_--) {
        solve();
    }
}
```

# Fragmentation

## 题目描述

不久前，一种名为 mesosiderite 的稀有陨石落在 Tomorrow Programming School 的场地内，并立刻被收集起来。学校获得了组织切割陨石的荣誉，切割后的较小碎片将被出口到世界各地的实验室。Swiss Precision Cutting Agency，简称 SPCA，被雇来完成切割工作。

SPCA 操作各种切割机器。每台机器可以把陨石或某块陨石碎片切成若干个更小的碎片，并且每个小碎片重量完全相同。产生的小碎片数量是该机器的特征值，不能改变。

SPCA 很确定，他们的每台机器一天内可以处理任意数量的陨石碎片。由某台机器切割产生的碎片不能在同一天再次被同一台机器切割，因为这可能导致交叉污染并造成精度损失。

每天恰好有一台切割机器可用。连续日期中可用机器的顺序是固定的。SPCA 制作了一份未来若干天的列表，并为每天指定了当天可用机器的特征值。SPCA 称这份列表为切割日程。切割过程需要持续一天或多天，直到获得令人满意数量的陨石碎片。

切割和出口过程还受到以下规则约束：

- 所有实验室都要求收到相同总重量的陨石碎片。
- 任意一块陨石碎片不能在多个实验室之间共享。
- 每块陨石碎片都必须交给某个实验室，不能有剩余。
- 在切割过程每天结束时，所有陨石碎片的重量必须相同，以简化切割管理。
- 整个切割过程必须在一段连续日期内完成，中间不能有不切割的日子。

学校已经拿到了切割日程，需要决定实际在哪些天进行切割。一个切割区间可以是切割日程中的任意连续日期序列。有些切割区间是有利的，有些不是。

如果从某个切割区间的第一天开始切割，并在该区间最后一天结束时得到的陨石碎片能够满足实验室需求，则这个切割区间称为有利区间。

学校需要一个程序，判断给定切割区间是否有利。

### 输入格式

第一行包含一个整数 $N$，表示切割日程中的天数，满足 $1 <= N <= 10^5$。

第二行包含整数序列 $a_1,a_2,...,a_N$，表示切割日程，满足 $1 <= a_i <= 10^6$。$a_i$ 表示第 $i$ 天可用机器的特征值。

第三行包含一个整数 $Q$，表示询问数量，满足 $1 <= Q <= 10^5$。

接下来 $Q$ 行，每行表示一个询问，包含三个整数 $s_i,t_i,k_i$，分别表示切割区间第一天、最后一天和参与的实验室数量，满足 $1 <= s_i <= t_i <= N$，$1 <= k_i <= 10^6$。

### 输出格式

对于每个询问，单独输出一行。如果该询问指定的切割区间是有利的，输出 `Yes`；否则输出 `No`。

## 题解

问题等价于判断 `k` 是否整除区间乘积 $a_s * a_{s+1} * ... * a_t$。

预处理 $1..10^6$ 的最小质因子。对每个 $a_i$ 分解质因数，把每个质因子出现的位置 $i$ 加入对应列表，重复因子重复加入。这样某个质因子在区间 $[s,t]$ 的出现次数可以用二分统计。

每次询问分解 `k`，得到每个质因子需要的次数。对每个质因子 `p`，检查它在 $[s,t]$ 中的出现次数是否不少于需求次数；全部满足则输出 $Yes$，否则输出 $No$。

复杂度：筛法 $O(A log log A)$，每个数分解约 $O(log A)$；每个询问为 $O(因子数 * log N)$，其中 $A=10^6$。空间 $O(A + 总因子出现次数)$。

```c++
#include <bits/stdc++.h>
using namespace std;
typedef long long int ll;
#define P pair<ll,ll>
#define MAXA (1e6+7)

vector<int> eratosthenesExt(int upTo) {
  vector<bool> v(upTo + 1, false);
  vector<int> sp(upTo + 1, 0);
  for (int i = 2; i <= upTo; ++i) {
    if (!v[i]) {
      for (int j = 2*i; j <= upTo; j += i) {
        if (!v[j]) {
          v[j] = true;
          sp[j] = i;
        }
      }
      sp[i] = i;
    }
  }
  sp[1] = 1;
  return sp;
}

// rychla faktorizace v O(log(n)) za pomoci rozsireneho sita
vector<int> fastFactors(int n, vector<int> & sieve) {
  int c;
  vector<int> divs;
  if (n == 1) return divs;
  divs.push_back(sieve[n]);

  n /= sieve[n];
  while (n != 1) {
    c = sieve[n];
    divs.push_back(c);
    n = n/sieve[n];
  }
  return divs;
}

vector<ll> a;

ll count_elements(vector<ll> & a, ll s, ll t) {
  auto st = lower_bound(a.begin(), a.end(), s);
  if (st == a.end()) return 0;
  auto en = upper_bound(a.begin(), a.end(), t);
  if (en == a.begin()) return 0;
  return distance(st, en);
}

int main(){
  ll n;
  cin>>n;
  a = vector<ll>(n);
  auto sieve = eratosthenesExt(MAXA);

  map<ll,vector<ll>> pri;
  for (int i = 0; i < n; ++ i) {
    cin >> a[i];
    for (auto f: fastFactors(a[i], sieve)) pri[f].push_back(i);
  }

  ll q;
  cin>>q;
  for (int i = 0; i < q; ++ i) {
    ll s, t, k;
    cin>>s>>t>>k;
    s --; t --;
    auto pr = fastFactors(k, sieve);
    map<ll,ll> prCnt;
    for (auto p: pr) prCnt[p] ++;
    bool ok = true;
    for (auto p: pr) {
      ll cnt = count_elements(pri[p], s, t);
      ok &= prCnt[p] <= cnt;
    }
    cout << (ok ? "Yes" : "No") << endl;
  }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100000;
const int MAXQ = 100000;
const int MAXV = 1000000;  // a_i, k <= 1e6

int N, Q;
int a[MAXN + 5];

// 欧拉筛
int min_prime[MAXV + 5];
vector<int> primes;
void sieve() {
    for (int i = 2; i <= MAXV; ++i) {
        if (min_prime[i] == 0) {
            min_prime[i] = i;
            primes.push_back(i);
        }
        for (int p : primes) {
            if (p > min_prime[i] || i * p > MAXV) break;
            min_prime[i * p] = p;
        }
    }
}

// 每个 a[i] 的质因子分解 (质因子, 指数)
vector<pair<int, int>> factors[MAXN + 5];

// 分解一个数，返回 vector<pair<int,int>>
vector<pair<int, int>> factorize(int x) {
    vector<pair<int, int>> res;
    while (x > 1) {
        int p = min_prime[x];
        int cnt = 0;
        while (x % p == 0) {
            x /= p;
            cnt++;
        }
        res.emplace_back(p, cnt);
    }
    return res;
}

// 莫队相关
int block;
struct Query {
    int l, r, k, id;
    bool operator<(const Query &other) const {
        if (l / block != other.l / block)
            return l / block < other.l / block;
        // 奇偶排序优化
        return ((l / block) & 1) ? (r > other.r) : (r < other.r);
    }
} qs[MAXQ + 5];

int cnt[MAXV + 5];  // 当前区间各质因子的指数和
bool ans[MAXQ + 5];

void add(int idx) {
    for (auto &[p, e] : factors[idx]) {
        cnt[p] += e;
    }
}

void remove(int idx) {
    for (auto &[p, e] : factors[idx]) {
        cnt[p] -= e;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    sieve();

    cin >> N;
    for (int i = 1; i <= N; ++i) {
        cin >> a[i];
        factors[i] = factorize(a[i]);
    }

    cin >> Q;
    for (int i = 1; i <= Q; ++i) {
        cin >> qs[i].l >> qs[i].r >> qs[i].k;
        qs[i].id = i;
    }

    block = max(1, int(N / sqrt(Q)));
    sort(qs + 1, qs + Q + 1);

    int curL = 1, curR = 0;
    for (int i = 1; i <= Q; ++i) {
        int L = qs[i].l, R = qs[i].r, K = qs[i].k;
        while (curL > L) add(--curL);
        while (curR < R) add(++curR);
        while (curL < L) remove(curL++);
        while (curR > R) remove(curR--);

        // 检查 K 的质因子需求
        vector<pair<int, int>> need = factorize(K);
        bool ok = true;
        for (auto &[p, e] : need) {
            if (cnt[p] < e) {
                ok = false;
                break;
            }
        }
        ans[qs[i].id] = ok;
    }

    for (int i = 1; i <= Q; ++i) {
        cout << (ans[i] ? "Yes" : "No") << '\n';
    }

    return 0;
}
```
