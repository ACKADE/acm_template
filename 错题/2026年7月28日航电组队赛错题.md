# toys

## 题目描述

小 H 是一家幼儿园的园长，幼儿园里面有 $n$ 个小朋友。

小 H 想给小朋友买一件玩具。

玩具店一共有 $m$ 种玩具，每个小朋友会喜欢这 $m$ 种玩具的一部分。

由于物以稀为贵，当某种玩具的库存越来越少的时候，那么它的单价将会越来越贵。

具体的，如果第 $j$ 次购买第 $i$ 件玩具的话，将会花费 $w_{i,j}$ 的价格，保证 $w_{i,j} \ge w_{i,j-1}$。

小 H 想知道，在能够为所有小朋友买到一件心仪的玩具的情况下，怎么样才能花费最少。

#### 输入格式

第一行一个整数 $T$（$1 \le T \le 10$），表示数据组数。

对于每组数据，第一行输入两个整数 $n, m$（$1 \le n, m \le 1000$），表示小朋友个数以及玩具个数。

接下来 $n$ 行，第 $i$ 行会先输入一个正整数 $x_i$，表示第 $i$ 个小朋友喜欢的玩具个数；接下来会输入 $x_i$ 个不同的正整数，表示第 $i$ 个小朋友喜欢的玩具编号。保证每组数据中，$\sum x_i \le 10^4$。

接下来 $m$ 行，每行先输入一个整数 $y_i$，保证 $y_i$ 等于这个玩具被多少个学生喜欢；接下来会输入 $y_i$ 个正整数，其中第 $j$ 个表示 $w_{i,j}$（$1 \le w_{i,j} \le 10^9$）。

#### 输出格式

对于每组数据，输出所需要花费的最小值。

##### 样例输入

```c++
1
3 2
1 1
2 1 2
1 2
2 3 100
2 50 200
```

##### 样例输出

```c++
153
```

## 题解

```c++
#include<bits/stdc++.h>
#define int long long
#define endl '\n'
using namespace std;
constexpr int N = 15000 + 5; // 节点上限
constexpr int M = 200000 + 5; // 边上限
constexpr int INF = 0x3f3f3f3f3f3f3f3f;
#define MOD debug;

int n, m, tot = 1, lnk[N], cur[N], ter[M], nxt[M], cap[M];
int cost[M], dis[N], ret;
bool vis[N];

void add(int u, int v, int w, int c) {
    ter[++tot] = v, nxt[tot] = lnk[u], lnk[u] = tot, cap[tot] = w, cost[tot] = c;
}

void addedge(int u, int v, int w, int c) {
    add(u, v, w, c), add(v, u, 0, -c);
}

bool spfa(int s, int t) {
    memset(dis, 0x3f, sizeof(dis));
    memcpy(cur, lnk, sizeof(lnk));
    std::queue<int> q;
    q.push(s), dis[s] = 0, vis[s] = true;
    while (!q.empty()) {
        int u = q.front();
        q.pop(), vis[u] = false;
        for (int i = lnk[u]; i; i = nxt[i]) {
            int v = ter[i];
            if (cap[i] && dis[v] > dis[u] + cost[i]) {
                dis[v] = dis[u] + cost[i];
                if (!vis[v]) q.push(v), vis[v] = true;
            }
        }
    }
    return dis[t] != INF;
}

int dfs(int u, int t, int flow) {
    if (u == t) return flow;
    vis[u] = true;
    int ans = 0;
    for (int &i = cur[u]; i && ans < flow; i = nxt[i]) {
        int v = ter[i];
        if (!vis[v] && cap[i] && dis[v] == dis[u] + cost[i]) {
            int x = dfs(v, t, std::min(cap[i], flow - ans));
            if (x) ret += x * cost[i], cap[i] -= x, cap[i ^ 1] += x, ans += x;
        }
    }
    vis[u] = false;
    return ans;
}

int mcmf(int s, int t) {
    int ans = 0;
    while (spfa(s, t)) {
        int x;
        while ((x = dfs(s, t, 0x3f3f3f3f))) ans += x;
    }
    return ans;
}

void solve() {
    cin >> n >> m;
    std::vector<std::vector<int> > like(n + 1);
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        like[i].resize(x);
        for (int j = 0; j < x; j++) {
            cin >> like[i][j];
        }
    }
    std::vector<std::vector<int> > w(m + 1);
    int sum_y = 0;
    for (int i = 1; i <= m; i++) {
        int y;\
        cin >> y;
        w[i].resize(y);
        for (int j = 0; j < y; j++) {
            cin >> w[i][j];
        }
        sum_y += y;
    }
    tot = 1;
    memset(lnk, 0, sizeof(lnk));
    ret = 0;
    int S = 0;
    int T = n + m + sum_y + 1;
    for (int i = 1; i <= n; i++) {
        addedge(S, i, 1, 0);
    }
    for (int u = 1; u <= n; u++) {
        for (int v: like[u]) {
            addedge(u, n + v, 1, 0);
        }
    }
    int base = n + m + 1;
    for (int v = 1; v <= m; v++) {
        int y = (int) w[v].size();
        for (int k = 0; k < y; k++) {
            int supply_node = base + k;
            addedge(n + v, supply_node, 1, w[v][k]);
            addedge(supply_node, T, 1, 0);
        }
        base += y;
    }
    mcmf(S, T);
    cout << ret << endl;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    int _ = 1;
    cin >> _;
    //	cout<<fixed<<setprecision(1);
    while (_--) {
        solve();
    }
    return 0;
}

```

# rains

## 题目描述

下雨了。

一共有 $n$ 块石头，第 $i$ 块石头高度为 $h_i$，这些石头初始是连接在一起的。

如果下雨，当雨水高度大于 $h_i$ 的时候，这块石头就会被淹没。

因此，在下雨的时候，露出水面的石头们会变成多个连续段。

小 H 每次询问：拿出区间 $[l, r]$ 的石头，至少形成 $k$ 个连续段的情况下，最高的雨水高度是多少。

### 输入格式

第一行三个整数 $n, T, k$（$1 \le n, T, k \le 10^6$），表示石头个数和询问次数以及要求的连续段数量。

接下来一行输入 $n$ 个正整数，每个表示石头高度 $h_i$（$1 \le h_i \le 10^6$）。

接下来 $T$ 行，每行两个正整数 $l, r$（$1 \le l \le r \le n$），表示一次询问。

### 输出格式

每个询问输出一个整数表示答案，如果这组询问无解，输出 $-1$。

#### 样例输入

```c++
10 10 3
8 10 7 9 5 2 6 1 4 5
3 4
6 6
3 4
1 9
1 8
2 9
5 7
5 10
4 7
6 10
```

#### 样例输出

```c++
-1
-1
-1
4
-1
4
-1
5
-1
-1
```
