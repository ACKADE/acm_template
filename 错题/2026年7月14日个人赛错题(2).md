# 垃圾进，垃圾出

## 题目描述

现在是 2525 年 7 月 25 日。随着大语言模型（LLM）的使用变得无处不在，要在互联网上找到真正由人类创作的文章，同时不迷失在大语言模型生成的各种胡言乱语中，已经几乎不可能了。

幸运的是——或者说不幸的是——大语言模型技术已经严重退步。神经网络所使用的训练数据大多由较早的大语言模型生成，而那些较早的模型又是在年代更久远、被反复利用的数据上训练的。因此，大多数大语言模型如今只会输出一个很长的小写字母字符串，其中每个字符都彼此独立地从所有小写字母中等概率随机选取。

你决定编写一个程序，在互联网上搜寻由人类创作的文章。你的程序必须判断给定文本是由人类创作的，还是由大语言模型生成的。

保证给定文本恰好属于以下两种情况之一：

- 由人类创作：文本是从给定单词表中选取若干单词，并在不添加空格的情况下按固定顺序拼接而成的字符串。
- 不是由人类创作，因此由大语言模型生成：每个字符都彼此独立地从所有小写字母中等概率随机选取。

### 输入格式

所有输入字符串都只包含英文小写字母（`a-z`）。

你的程序将恰好在 100 个测试用例上运行，并且所有测试用例都满足 $|s| = 3 \cdot 10^5$ 且 $n = 5000$。样例规模较小，仅用于说明。

对于每个由人类创作的测试用例，$s$ 表示的文本由人类创作，并且 $s$ 是固定的，在你每次提交时都不会发生变化。对于每个由大语言模型生成的测试用例，$s$ 由大语言模型生成，你的每次提交都会收到一个新的字符串 $s$；该字符串通过彼此独立、等概率地随机选取英文小写字母（`a-z`）生成。

## 题解

题目类型:**AC自动机+dp**或者**随机数的性质**

**问题**：判断一段文本是人类写的，还是由大语言模型（LLM）生成的。

**问题**：判断一段文本是人类写的，还是由大语言模型（LLM）生成的。

**观察**：在随机文本中，几乎所有长度为 6 的子串（6-mer）都互不相同，因为
26⁶ ≈ 300,000,000 ≫ 300,000。

**解法**：如果所有 6-mer 最多出现两次，则判定文本为 LLM 生成，否则判定为人类所写。

**替代方案**：也可以改为统计不同 6-mer 的数量。

```c++
#include <bits/stdc++.h>
using namespace std;

const int N = 50005;      // 字典树最多节点数，5000个单词 * 10 = 50000
const int M = 300005;     // 文本最大长度

int tr[N][26], fail[N], cnt;
int word_len[N];          // 记录以节点结尾的单词长度（0 表示不是单词结尾）
bool dp[M];               // dp[i] 表示前 i 个字符能否拼接

// 构建失配指针，并补全转移边（你的原板子）
void built() {
    queue<int> q;
    for (int i = 0; i < 26; i++) {
        if (tr[0][i]) {
            q.push(tr[0][i]);
        }
    }
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int i = 0; i < 26; i++) {
            if (tr[u][i]) {
                fail[tr[u][i]] = tr[fail[u]][i];
                q.push(tr[u][i]);
            } else {
                tr[u][i] = tr[fail[u]][i];
            }
        }
    }
}

void solve() {
    // ----- 输入部分 -----
    string text;
    cin >> text;          // 先读入待判断的文本 s
    int n;
    cin >> n;             // 单词个数
    for (int i = 0; i < n; i++) {
        string w;
        cin >> w;
        int m = w.size();
        int now = 0;
        for (int j = 0; j < m; j++) {
            int tmp = w[j] - 'a';
            if (tr[now][tmp] != 0) {
                now = tr[now][tmp];
            } else {
                tr[now][tmp] = ++cnt;
                now = cnt;
            }
        }
        word_len[now] = m;   // 记录单词终点及其长度
    }

    // ----- 构建 AC 自动机 -----
    built();

    // ----- DP 判断能否完全拼接 -----
    int m = text.size();
    dp[0] = true;            // 空前缀可拼接
    int p = 0;
    for (int i = 0; i < m; i++) {
        int tmp = text[i] - 'a';
        p = tr[p][tmp];      // 自动机转移
        // 遍历所有以当前位置 i 结尾的单词
        for (int t = p; t; t = fail[t]) {
            if (word_len[t]) {
                int len = word_len[t];
                int l = i - len + 1;       // 单词左端点
                if (l >= 0 && dp[l]) {     // 前面部分能拼接，则当前位置可拼接
                    dp[i + 1] = true;
                    break;                 // 只要找到一个就能确定 dp[i+1] 为真
                }
            }
        }
    }

    // ----- 输出结果 -----
    if (dp[m])
        cout << "yes\n";
    else
        cout << "no\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    solve();
    return 0;
}
```

# 博格尔排序

## 题目描述

现在是 2025 年 2 月 25 日。你和朋友们又度过了一个兴致高昂的博格尔游戏之夜。所有人离开后，你已经把公寓彻底收拾干净，只剩下把博格尔骰子托盘整理好。你开始思考：能否不交换任何骰子的位置，只通过旋转骰子，就让托盘中的字母按字母表顺序排列？

博格尔托盘由 16 个六面骰子组成。每个骰子的每一面都标有一个英文字母。其中恰有一个骰子的一面标有 `Qu`。同一个骰子上，任何字母出现的次数都不会达到 4 次。将一个骰子翻转一次，可以让当前朝向侧面的任意一个字母转到顶面；将一个骰子翻转两次，则可以让当前朝下的字母转到顶面。

请按照标准阅读顺序，即从左到右、从上到下，使托盘顶面的内容按字母表非递减顺序排列，并使翻转总次数尽可能少。字母大小写不影响比较；包含两个字母的骰面视为依次出现的 `Q` 和 `U`，因此 `QuU` 是有序的，而 `QuT` 不是。

## 题解

#### 1. 图论（有向无环图最短路）

- 将16个骰子的6个面视为节点（共96个）。
- 从骰子 c*c* 的面 r*r* 向骰子 c+1*c*+1 的面 r′*r*′ 连边，当且仅当 r*r* 的字母 ≤ r′*r*′ 的字母。
  - 边权：顶面→0，侧面→1，底面→2。
- 添加源点连向第一个骰子各面，最后一个骰子各面连向汇点。
- 求源到汇的最短路即答案。
- **陷阱**：`Q`（代表 `Qu`）不能与 `T` 等字母直接比较（因为实际是 `U` 在比较，`U > T`），必须特殊处理。
- 复杂度 O(16×6)*O*(16×6)，因图为DAG可用DP线性求解。

#### 2. 动态规划（DP）

- 定义 f(i,x)*f*(*i*,*x*)：处理完前 i*i* 个骰子，且第 i*i* 个骰子顶面显示字母 x*x* 时的最小转动次数。
- 转移：f(i,x)=min⁡y≤x{f(i−1,y)+cost(i,x)}*f*(*i*,*x*)=*y*≤*x*min{*f*(*i*−1,*y*)+cost(*i*,*x*)}，其中 y*y* 为第 i−1*i*−1 个骰子可能展示的字母，costcost 为将第 i*i* 个骰子翻到 x*x* 的代价（0/1/2）。
- 同样注意 `Q` 作为 `Qu` 的两阶段比较。
- 复杂度 O(16×26×6)*O*(16×26×6)，极快。

```c++
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N = 20;
string up, mid, down;
int dp[N][27];

void solve() {
    cin >> up;
    string all;
    for (int i = 1; i <= 4; i++) {
        string ls;
        cin >> ls;
        all += ls;
    }
    for (int i = 0; i < 16; i++) {
        mid += all[i];
        mid += all[16 + i];
        mid += all[32 + i];
        mid += all[48 + i];
    }
    for (int i = 0; i < 16; i++) {
        for (int j = 0; j < 26; j++) {
            dp[i][j] = INT_MAX;
        }
    }
    cin >> down;

    // 初始化 dp[0]，全部用 min 防止覆盖更优解
    if (up[0] == 'Q') {
        dp[0]['U' - 'A'] = min(dp[0]['U' - 'A'], 0LL);
    } else {
        dp[0][up[0] - 'A'] = min(dp[0][up[0] - 'A'], 0LL);
    }
    if (down[0] == 'Q') {
        dp[0]['U' - 'A'] = min(dp[0]['U' - 'A'], 2LL);
    } else {
        dp[0][down[0] - 'A'] = min(dp[0][down[0] - 'A'], 2LL);
    }
    if (mid[0] == 'Q') {
        dp[0]['U' - 'A'] = min(dp[0]['U' - 'A'], 1LL);
    } else {
        dp[0][mid[0] - 'A'] = min(dp[0][mid[0] - 'A'], 1LL);
    }
    if (mid[1] == 'Q') {
        dp[0]['U' - 'A'] = min(dp[0]['U' - 'A'], 1LL);
    } else {
        dp[0][mid[1] - 'A'] = min(dp[0][mid[1] - 'A'], 1LL);
    }
    if (mid[2] == 'Q') {
        dp[0]['U' - 'A'] = min(dp[0]['U' - 'A'], 1LL);
    } else {
        dp[0][mid[2] - 'A'] = min(dp[0][mid[2] - 'A'], 1LL);
    }
    if (mid[3] == 'Q') {
        dp[0]['U' - 'A'] = min(dp[0]['U' - 'A'], 1LL);
    } else {
        dp[0][mid[3] - 'A'] = min(dp[0][mid[3] - 'A'], 1LL);
    }

    for (int i = 1; i < 16; i++) {
        for (int j = 0; j < 26; j++) {
            if (dp[i-1][j] == INT_MAX) continue;   // 修正溢出

            // 顶面
            if (j <= up[i] - 'A') {
                if (up[i] == 'Q') {
                    dp[i]['U' - 'A'] = min(dp[i]['U' - 'A'], dp[i - 1][j]);
                } else {
                    dp[i][up[i] - 'A'] = min(dp[i][up[i] - 'A'], dp[i - 1][j]);
                }
            }
            // 底面
            if (j <= down[i] - 'A') {
                if (down[i] == 'Q') {
                    dp[i]['U' - 'A'] = min(dp[i]['U' - 'A'], dp[i - 1][j] + 2);
                } else {
                    dp[i][down[i] - 'A'] = min(dp[i][down[i] - 'A'], dp[i - 1][j] + 2);
                }
            }
            // 四个侧面
            if (j <= mid[i * 4] - 'A') {
                if (mid[i * 4] == 'Q') {
                    dp[i]['U' - 'A'] = min(dp[i]['U' - 'A'], dp[i - 1][j] + 1);
                } else {
                    dp[i][mid[i * 4] - 'A'] = min(dp[i][mid[i * 4] - 'A'], dp[i - 1][j] + 1);
                }
            }
            if (j <= mid[i * 4 + 1] - 'A') {
                if (mid[i * 4 + 1] == 'Q') {
                    dp[i]['U' - 'A'] = min(dp[i]['U' - 'A'], dp[i - 1][j] + 1);
                } else {
                    dp[i][mid[i * 4 + 1] - 'A'] = min(dp[i][mid[i * 4 + 1] - 'A'], dp[i - 1][j] + 1);
                }
            }
            if (j <= mid[i * 4 + 2] - 'A') {
                if (mid[i * 4 + 2] == 'Q') {
                    dp[i]['U' - 'A'] = min(dp[i]['U' - 'A'], dp[i - 1][j] + 1);
                } else {
                    dp[i][mid[i * 4 + 2] - 'A'] = min(dp[i][mid[i * 4 + 2] - 'A'], dp[i - 1][j] + 1);
                }
            }
            if (j <= mid[i * 4 + 3] - 'A') {
                if (mid[i * 4 + 3] == 'Q') {
                    dp[i]['U' - 'A'] = min(dp[i]['U' - 'A'], dp[i - 1][j] + 1);
                } else {
                    dp[i][mid[i * 4 + 3] - 'A'] = min(dp[i][mid[i * 4 + 3] - 'A'], dp[i - 1][j] + 1);
                }
            }
        }
    }

    int ans = INT_MAX;
    for (int i = 0; i < 26; i++) {
        ans = min(ans, dp[15][i]);
    }
    if (ans == INT_MAX) {
        cout << "impossible" << endl;
    } else {
        cout << ans << endl;
    }
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(0); cout.tie(0);
    int _ = 1;
    while (_--) {
        solve();
    }
    return 0;
}
```

## 题解

### 核心观察

- 设 w*w* 为游走中离 v1*v*1 最远的节点（BFS 深度最大）。
- 从 w*w* 必须存在两条返回 v1*v*1 的路径，且它们在 w*w* 的第一步走向不同的邻居。
- 最优解下，这两条路径的长度之和应最小。
- 每条路径的长度 = 1+w 相应邻居的深度1+*w* 相应邻居的深度。
- 这两条路径会分别经过 w*w* 的两个离 v1*v*1 最近的邻居。

------

### 解法（BFS + 枚举最远点）

1. 从 v1*v*1 运行 BFS，记录每个节点的深度。
2. 对于每个节点 w*w*（作为候选最远点），找到它到 v1*v*1 的两条最短路径（分别从不同邻居出发），计算总长度。
3. 当某个节点在 BFS 中第二次被访问时，即可得到第二条路径的长度（节点深度 + 该路径长度），并更新最优解。
4. 选出使总长度最小的最远节点 w*w*（若存在），重构整条闭合游走。

**复杂度**：O(n+m)*O*(*n*+*m*)，因为只需一次 BFS 并线性扫描节点。

```c++
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N = 1e6 + 10;
vector<int> ljb[N];

void solve() {
    int n, m;
    cin >> n >> m;
    vector<pair<int,int> > edges;
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        ljb[u].push_back(v);
        ljb[v].push_back(u);
        edges.push_back({u, v});
    }

    // BFS 求最短路径树
    vector<int> depth(n + 1, -1), parent(n + 1, 0);
    queue<int> q;
    depth[1] = 0;
    q.push(1);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int v: ljb[u]) {
            if (depth[v] == -1) {
                depth[v] = depth[u] + 1;
                parent[v] = u;
                q.push(v);
            }
        }
    }

    const int INF = 1e9;
    int ans = INF;
    int best_u = -1, best_v = -1;

    // 枚举非树边，找包含1的最小环
    for (auto &e: edges) {
        int u = e.first, v = e.second;
        if (depth[u] == -1 || depth[v] == -1) continue; // 不可达
        if (parent[u] == v || parent[v] == u) continue; // 树边，不是环
        int cand = depth[u] + depth[v] + 1; // 环的边数
        if (cand < ans) {
            ans = cand;
            best_u = u;
            best_v = v;
        }
    }

    if (ans == INF) {
        cout << "impossible\n";
        return;
    }

    // 重构路径：1 → best_u → best_v → 回到1
    vector<int> path_u, path_v;
    for (int cur = best_u; cur != 0; cur = parent[cur]) {
        path_u.push_back(cur);
    }
    reverse(path_u.begin(), path_u.end()); // 1 到 best_u
    for (int cur = best_v; cur != 0; cur = parent[cur]) {
        path_v.push_back(cur);
    } // best_v 到 1
    vector<int> walk = path_u; // 1 ... best_u
    walk.push_back(best_v); // best_u → best_v
    for (size_t i = 1; i < path_v.size(); i++) {
        walk.push_back(path_v[i]); // parent[best_v] ... 1
    }
    cout << walk.size() << "\n";
    for (size_t i = 0; i < walk.size(); i++) {
        if (i > 0) cout << " ";
        cout << walk[i];
    }
    cout << "\n";
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int _ = 1;
    while (_--) {
        solve();
    }
    return 0;
}

```

# 异或魔法

## 题目描述

兹因克索斯找到了一个宝藏，正准备拿，发现宝藏被封印了，封印是一个长度为 $n$ 的单调不下降的正整数数列，要破坏这个封印，必须使它不再单调不下降。

按理说这不难，但是兹因克索斯上学的时候把魔法课都旷了，只会一招“异或魔法”，就是选两个**相邻**的数，移除，再把这两个数的按位异或和插入原来的位置。比如说封印是 $[2,5,6,8]$，兹因克索斯对 $5, 6$ 使用魔法，$5⊕6=3$，就会变成 $[2, 3, 8]$。

由于兹因克索斯能力有限，请帮他求出他最少要使用几次魔法才能破坏封印。如果他无法只用异或魔法破坏封印，输出 $-1$。

特别地：如果封印只剩一个数字，它依旧被视作单调不下降，并且兹因克索斯无法再进一步破坏它。

### 输入格式

第一行，一个整数 $n$，表示封印的长度。

$n$ 个整数，$a_1,a_2 \dots a_n$，表示封印的内容。保证是一个单调不下降的正整数数列。

$2 \leq n \leq 10^5$
$1 \leq a_i \leq 10^9$

### 输出格式

输出一个整数，表示兹因克索斯最少要使用几次魔法才能破坏封印。如果他无法只用异或魔法破坏封印，输出 $-1$。

#### 样例输入 #1

```plain
4
2 5 6 8
```

#### 样例输出 #1

```plain
1
```

#### 样例输入 #2

```plain
3
1 2 3
```

#### 样例输出 #2

```plain
-1
```

#### 样例输入 #3

```plain
5
1 2 4 6 20
```

#### 样例输出 #3

```plain
2
```

### 提示

第一个样例，兹因克索斯对 $2, 5$ 使用魔法，$2⊕5=7$，封印变成 $[7, 6, 8]$，不再单调不下降。
第二个样例，兹因克索斯无法破坏封印。
第三个样例，兹因克索斯对 $1, 2$ 使用魔法，$1⊕2=3$，封印变成 $[3, 4, 6, 20]$，他再对 $3, 4$ 使用魔法，$3⊕4=7$，封印变成 $[7, 6, 20]$，不再单调不下降。

## 题解

首先，计算出数组 $b_1, b_2, \dots, b_n$，其中 $b_i$ 表示 $a_i$ 二进制表示中最高位 $1$ 的位置。这些值可以通过将给定数字不断除以 $2$ 直到为零来得到。

注意：如果存在某个下标 $i$ 满足 $b_{i-1} = b_i = b_{i+1} = t$，那么我们可以对 $a_i$ 和 $a_{i+1}$ 进行一次操作，得到的结果会比 $a_{i-1}$ 小。这是因为 $a_{i-1}$ 的最高位是 $t$，而 $a_i \oplus a_{i+1}$ 的第 $t$ 位及更高位都是零。因此，如果存在这样的 $i$（很容易在一次线性扫描中检查出来），答案就是 $1$。

接下来，如果没有这样的 $i$，则数组长度 $n$ 不会超过 $2 \times (\lfloor \log_2 10^9 \rfloor + 1) = 60$。因为拥有相同最高位的数最多只能有两个。在数据规模这么小的约束下，问题就变得简单多了。

考虑任意一种最终方案，记最终得到的数组为 $c$，其中一定存在某个 $i$ 使得 $c_i > c_{i+1}$。注意到最终数组的每个元素都等于初始数组的某个连续子段的异或值，并且初始数组的每个元素恰好属于一个这样的子段。设 $c_i$ 对应的子段为 $a_l, a_{l+1}, \dots, a_m$，$c_{i+1}$ 对应的子段为 $a_{m+1}, a_{m+2}, \dots, a_r$。那么显然，要找到最优解，只需枚举所有可能的 $l$、$m$ 和 $r$，并检查左侧子段的异或值是否大于右侧子段的异或值。如果满足该不等式，就用 $r - l - 1$ 更新答案。这部分的复杂度根据实现方式为 $O(n^3)$ 或 $O(n^4)$。

```c++
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N = 1e6 + 10;
const int MOD = 1;
#define MOD debug;
int a[N];
int cd[N];
int pre[N];

void solve() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        int ls = a[i];
        while (ls) {
            cd[i]++;
            ls /= 2;
        }
        pre[i] = a[i] ^ pre[i - 1];
    }
    for (int i = 3; i <= n; i++) {
        if (cd[i] == cd[i - 1] && cd[i - 1] == cd[i - 2]) {
            cout << 1 << endl;
            return;
        }
    }
    int ans = INT_MAX;
    for (int l = 1; l < n; l++) {
        for (int r = l + 1; r <= n; r++) {
            for (int m = l; m < r; m++) {
                if ((pre[r] ^ pre[m]) < (pre[m] ^ pre[l - 1])) {
                    ans = min(ans, r - l - 1);
                }
            }
        }
    }
    if (ans == INT_MAX) {
        cout << -1 << endl;
    } else {
        cout << ans << endl;
    }
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int _ = 1;
    //	cin>>_;
    //	cout<<fixed<<setprecision(1);
    while (_--) {
        solve();
    }
    return 0;
}

```

# 友好组队

## 题目描述

今年，共有 $n$ 名选手参加大型年度彩弹竞赛（BAPC）。这是一项大型全国赛事，蓝队和红队将在比赛中争夺全国冠军。前来参赛的选手中，有些人彼此认识，而另一些人互不相识。

在去年的 BAPC 中，这导致了一些令人遗憾的沟通事故，整场活动不得不提前结束：蓝队有一半队员不知为何跑到了相邻的场地，而红队竟奇迹般地夺走了自己的旗帜。

因此，今年的组织方决定：在两支队伍中，任意两名队员都必须已经彼此认识。此外，为了保证比赛公平，所有选手都必须被分配到某支队伍中，并且两支队伍的人数必须相等。能否将所有选手划分成满足这些条件的两支队伍？

### 输入格式

输入由以下内容组成：

- 一行包含两个整数 $n$ 和 $m$（$2 \le n \le 10^6$，$0 \le m \le 10^6$），分别表示选手数量和认识关系的数量。
- 接下来 $m$ 行，每行包含两个整数 $a$ 和 $b$（$1 \le a,b \le n$，$a \ne b$），表示选手 $a$ 和选手 $b$ 已经彼此认识。

任意一对选手之间的认识关系至多会在输入中出现一次。

### 输出格式

如果可以按照上述要求将所有选手划分为两支队伍，那么对于每名选手 $i$，如果选手 $i$ 应加入红队，则输出 `r`；如果选手 $i$ 应加入蓝队，则输出 `b`。否则输出 `impossible`。

如果存在多个有效答案，可以输出其中任意一个。

```plain
1 2
```

#### 样例输出 #1

```plain

b
```

#### 样例输入 #2

```plain

3 1
3 2
```

#### 样例输出 #2


## 题解

### 1. 问题转化
- **目标**：将原图划分成两个大小为 k = n/2 的团。
- **转化**：在原图的补图上，问题变为找两个大小为 k 的独立集，且覆盖所有点。
- 补图中，队伍内部必须无熟人 → 队伍内部在补图中无边 → 独立集。

### 2. 必要条件
- n 必须是偶数（否则无法平分）。
- 每个团内部需要 k(k-1)/2 条边，两队至少需要 k(k-1) 条边。若 m < k(k-1) 直接无解。
- 由 m ≤ 10^6 可推出有解时 n ≤ 2002，因此 O(n²) 算法可行。

### 3. 补图必须二分图
- 因为两个独立集覆盖全图，意味着补图可以被二染色（一个独立集染红色，一个染蓝色）。
- 每个连通分量必须自身是二分图，否则整体不可能是二分图。

### 4. 连通分量的两种选择
- 对补图的每个连通分量进行二分染色，得到两部分大小 (a_i, b_i)。
- 我们可以自由决定将 a_i 部分归入红队（原图红队）还是蓝队，对应 b_i 部分归入另一队。
- 问题变成：从每个分量中选一个数（a_i 或 b_i），使得总和为 k。

### 5. 背包 DP 判定与构造
- 定义 dp[i][s] = true/false，表示考虑前 i 个分量能否选出总和为 s 的红队人数。
- 转移：`dp[i][s] = dp[i-1][s - a_i] 或 dp[i-1][s - b_i]`
- 最后检查 dp[t][k] 是否为真（t 为分量个数）。
- 若可行，回溯 dp 记录每个分量的选择，将对应颜色映射为 `r` 或 `b` 输出。
