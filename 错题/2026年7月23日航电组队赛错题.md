# 键盘杀手

## 题目描述

河灵的键盘又积灰了。

河灵的键盘只有一排，共 $n$ 个键帽，其中第 $i$ 个键帽的高度为 $a_i$。特别地，我们认为键盘两侧各有一个高度为 $0$ 的“空键帽”（即 $a_0 = a_{n+1} = 0$）。

为了将键盘彻底清理干净，河灵需要将所有的键帽都拔下来。你可以进行若干次操作，每次操作形如：

选择一个正整数 $i$ ($1 \le i \le n$)，将第 $i$ 个键帽拔下来。由于拔键帽时会受到左右相邻位置键帽当前高度的影响，本次操作需要花费 $\max(a_{i-1}, a_{i+1})$ 的代价，然后将 $a_i$ 赋值为 $0$，表示该位置的键帽已被取下。
注意，每次操作的代价取决于操作发生时左右相邻位置键帽的当前高度，而不是这些键帽的初始高度。

请你帮帮河灵，求出将所有的键帽都拔下来的最小代价总和，即将 $a_1, a_2, \dots, a_n$ 均赋值为 $0$ 的最小代价总和。

### 输入格式

每个测试点中包含多组测试数据。输入的第一行包含一个正整数 $T$ ($1 \le T \le 10^6$)，表示数据组数。对于每组测试数据：

第一行一个正整数 $n$ ($1 \le n \le 10^5$)，表示序列长度。

第二行 $n$ 个正整数 $a_1, a_2, \dots, a_n$ ($1 \le a_i \le 10^9$)，表示初始的序列 $a$。

保证所有测试数据中 $n$ 之和不超过 $10^6$。

### 输出格式

对于每组测试数据：一行一个整数，表示最小代价总和。

#### 样例输入

```
3
6
7 5 9 10 5 7
10
9 14 19 7 6 9 16 14 12 6
20
47 83 21 45 58 61 46 91 41 74 94 27 23 27 85 82 91 96 69 36
```

#### 样例输出

```
23
60
596
```

## 题解

**Key Observation**：假设给这 $n$ 个数定一个操作顺序，那么删除 $i$ 对代价总和的贡献，只取决于 $i-1, i, i+1$ 的删除顺序。  
考虑 DP，设 $f_{i,0/1}$ 分别表示已经考虑了操作 $1,\dots,i$ 的代价，并且 $i$ 晚于/早于 $i-1$ 操作时的最小代价总和。转移方程比较简单。  
时间复杂度 $\mathcal{O}(n)$。

```c++
#include<bits/stdc++.h>
#define int long long
#define endl '\n'
using namespace std;
const int N = 1e6 + 10;
const int MOD = 1;
#define MOD debug;
int sz[N];
int dp[N][2]; //dp[i][0]代表i位置比前一个前取，dp[i][1]代表i位置比前一个后取

void solve() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> sz[i];
        dp[i][0] = 1e15;
        dp[i][1] = 1e15;
    }
    dp[1][0] = 0;
    dp[1][1] = 0;
    for (int i = 2; i <= n; i++) {
        dp[i][0] = min(dp[i - 1][0], dp[i - 1][1]) + sz[i - 1];
        dp[i][1] = min(dp[i - 1][0] - sz[i - 2] + max(sz[i - 2], sz[i]), dp[i - 1][1] + sz[i]);
    }
    cout << min(dp[n][0], dp[n][1]) << endl;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    int _ = 1;
    cin >> _;
    //	cout<<fixed<<setprecision(1);
    while (_--) {
        solve();
    }
    return 0;
}
```

# **幻灵战队 2**

“幻灵战队”是《金铲铲之战》S17 赛季中的一种娱乐羁绊。在本题中，我们简化了幻灵战队的机制：在开启了幻灵战队羁绊之后，玩家可以通过连败来获得科技点。

## 题解

**题目背景**  
首先，连败获得科技点的式子 $20+5x$ 的系数不影响求解答案，所以不妨认为式子是 $x$。  

记 $f(i,j)$ 表示：将一个长度为 $i$ 的全0段的$j$个0改成1之后，科技点总和的最小值。  
相当于将 $i-j$ 个数划分到 $j+1$个分段里，一个长度为 $L$ 的分段代价为 $\frac{L(L+1)}{2}$，要求所有段的代价之和最小。

最优的策略一定是平均分，因为如果有两个段段长相差大于1，那么将段长之差缩小一定会使得代价变小。那么有  

$f(i,j) = \frac{u(u+1)}{2} \cdot (j+1-r) + \frac{(u+1)(u+2)}{2} \cdot r$

其中  $u = \left\lfloor \frac{i-j}{j+1} \right\rfloor, \quad r = (i-j) \bmod (j+1)$

**原问题解法**  
回到原问题，需要先找出所有的全0段，显然不同的全0段之间是相互独立的。我们要考虑的是如何分配操作次数。

发现当 $i$ 固定时，$f(i,j) - f(i,j+1)$ 是随着 $j$的增大而减小的。也就是说，**每一段的“更新”收益是单调不增的**。  
所以，每次取出当前更新收益最大的段，令其操作次数 $+1$ 一定是最优的。可以使用大根堆维护上述过程。

# **最遥远的距离**

## 题面描述

还记得小时候，小河灵和胖胖龙常常结伴去公园游玩。公园有 $n$ 个景点与 $n-1$ 条双向道路，每条双向道路连接两个不同的景点，任意两个不同的景点都可以通过若干条双向道路到达。换言之，这些景点的连接形成了一棵树。

小河灵是一个喜欢探索的孩子，他想到公园的最远端瞧一瞧。为此，对于每个景点 $i$ ($1 \le i \le n$)，他都定义了该景点的探索度 $d_i$：从景点 $i$ 出发，沿着一条不经过重复景点的简单路径前进，最多能经过多少个不同的景点（包含起点本身）。

时过境迁，河灵慢慢长大，他已经记不清当年公园的具体模样了。但幸运的是，他的日记中仍然保存着当年记录下来的探索度序列 $d_1, d_2, \dots, d_n$。

河灵很想找回当年的感觉。请你帮帮河灵，构造一个有 $n$ 个景点与 $n-1$ 条双向道路的公园，该公园的任意两个不同景点都可以相互到达，并且每个景点 $i$ ($1 \le i \le n$) 的探索度恰好为 $d_i$。或判断不存在满足条件的公园。

### **输入格式**

每个测试点中包含多组测试数据。输入的第一行包含一个正整数 $T$ ($1 \le T \le 10^6$)，表示数据组数。对于每组测试数据：

第一行一个正整数 $n$ ($1 \le n \le 10^5$)，表示公园的景点个数。

第二行 $n$ 个正整数 $d_1, d_2, \dots, d_n$ ($1 \le d_i \le n$)，表示每个景点的探索度。

保证所有测试数据中 $n$ 之和不超过 $10^6$。

### **输出格式**

对于每组测试数据：若存在满足条件的公园，输出的第一行包含一个字符串 `Yes`。

接下来 $n-1$ 行，每行输出两个正整数 $x, y$ ($1 \le x, y \le n$)，表示你给出的公园中，存在一条连接景点 $x, y$ 的双向道路。

若存在多种满足条件的公园，输出任意一种即可。

若不存在满足条件的公园，输出一行一个字符串 `No`。

#### **样例输入**

```
2
7
5 5 5 4 4 4 3
3
2 2 2
```

#### **样例输出**

```
Yes
1 4
4 7
2 5
5 7
3 6
6 7
No
```

## 题解

**思路分析**

首先，$d$ 数组的最大值等于该树最长链（直径）的长度，因此一个必要条件是这条最长链必须存在。

具体地，设 $L, R$ 分别为 $d$ 数组的最小值与最大值，那么
$$L = \left\lfloor \frac{R}{2} \right\rfloor + 1$$
且对于所有满足 $L < i \le R$ 的 $i$，都要在 $d$ 数组中至少出现两次；并且当 $R$ 是奇数时，$L$ 要恰好出现一次；当 $R$ 是偶数时，$L$ 要恰好出现两次。

可以发现该条件也是充分的。我们先构造出一条最长链，那么剩下还没加入树中的节点 $x$ 必定满足 $L < d_x \le R$，只需将 $x$ 连向这条最长链的第 $R - d_x + 2$ 个点即可。

> **By the way**：一个点在树上的最远点，必定为树的直径的两个端点的其中之一。这个经典结论或许会更好地帮助你理解此题。

```c++
#include<bits/stdc++.h>
#define int long long
#define endl '\n'
using namespace std;
const int N = -1;
const int MOD = 1;
#define MOD debug;

void solve() {
    int n;
    cin >> n;
    vector<int> d(n);
    for (int i = 0; i < n; ++i) cin >> d[i];

    int R = *max_element(d.begin(), d.end());
    int L = *min_element(d.begin(), d.end());

    // 必要条件1：最小值与最大值的关系
    if (L != R / 2 + 1) {
        cout << "No" << endl;
        return;
    }
    vector<int> cnt(n + 1, 0);
    for (int x : d) cnt[x]++;
    bool ok = true;
    for (int i = L + 1; i <= R; ++i) {
        if (cnt[i] < 2) ok = false;
    }
    if (R % 2 == 1) {
        if (cnt[L] != 1) ok = false;
    } else {
        if (cnt[L] != 2) ok = false;
    }

    if (!ok) {
        cout << "No" << endl;
        return;
    }
    // 将节点按 d 值分类 (1‑based 编号)
    vector<vector<int>> nodes_by_d(n + 1);
    for (int i = 0; i < n; ++i) {
        nodes_by_d[d[i]].push_back(i + 1);
    }

    // 构造直径上的点序列 (d 值顺序)
    vector<int> chain_d;
    for (int i = 1; i <= R; ++i) {
        chain_d.push_back(max(i, R - i + 1));
    }

    vector<int> diam_seq;
    vector<int> ptr(n + 1, 0);
    for (int val : chain_d) {
        int idx = ptr[val]++;
        diam_seq.push_back(nodes_by_d[val][idx]);
    }

    cout << "Yes" << endl;
    // 输出直径上的边
    for (int i = 0; i < R - 1; ++i) {
        cout << diam_seq[i] << " " << diam_seq[i + 1] << endl;
    }
    // 输出多余节点的边
    for (int v = L + 1; v <= R; ++v) {
        int pos_idx = R - v + 1;      // 0‑based 下标
        int target = diam_seq[pos_idx];
        for (int j = ptr[v]; j < (int)nodes_by_d[v].size(); ++j) {
            cout << nodes_by_d[v][j] << " " << target << endl;
        }
    }
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    int _;
    cin >> _;
    while (_--) {
        solve();
    }
    return 0;
}
```

# **合成大 hdu**

## 题面描述

河灵是 hdu 的狂热粉丝。在他眼中，一切的一切都是 hdu 的模样。

有一天晚上，河灵在草稿纸上涂鸦时发现，他居然可以在一个字符串中窥见 hdu 的影子！对于一个字符串 $S$，河灵可以一下子就数出字符串 $S$ 的不同子序列 `hdu` 的个数。

简单的数数已经不能满足河灵了。河灵有一个正整数 $n$ ($1 \le n \le 10^9$)，河灵很想知道拥有不同子序列 `hdu` 个数恰好为 $n$ 的字符串 $S$ 是什么样的。

请你帮帮河灵，你需要构造一个仅包含 `h`、`d`、`u` 三种字符的字符串 $S$，使得字符串 $S$ 的不同子序列 `hdu` 的个数恰好等于 $n$。但是河灵的草稿纸大小有限，所以你构造的字符串长度不能超过 $3001$。

可以证明，对于所有满足 $1 \le n \le 10^9$ 的正整数 $n$，至少存在一种满足要求的构造方案。

**子序列**：如果 $S'$ 可以通过 $S$ 删除若干个（可能是零个或全部）元素，且不改变剩余元素的相对顺序得到，则称 $S'$ 是 $S$ 的子序列。

**不同的子序列**：两个子序列 $S_1, S_2$ 不同，当且仅当原序列中至少存在一个位置在一个子序列中出现，在另一个子序列中被删除。

一行一个正整数 $n$ ($1 \le n \le 10^9$)，表示构造的字符串 $S$ 需要包含的不同子序列 `hdu` 的个数。

### **输出格式**

对于每组测试数据：输出一行一个字符串 $S$ ($1 \le |S| \le 3001$)，表示你构造的字符串。你需要保证字符串 $S$ 仅包含 `h`、`d`、`u` 三种字符。
